Code contributions

Help improve the experience.

Before you submit

Keep the app mobile-friendly, accessible, and transparent. Avoid adding trackers, collecting sensitive data, or blending paid placement into editorial content.

How to contribute

Open an issue for a bug or feature idea, then submit a pull request with a clear description and a working update. See CONTRIBUTING.md for the process.

Safety guidelines

Never present outdoor recreation as a replacement for therapy or crisis care. Crisis support remains available at all times, and all content should be reviewed carefully before publishing.
